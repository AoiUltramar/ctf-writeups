# ctf-writeups

Writeups for the CTFs I played in 2026. Each one walks through how I solved
the challenge, including the dead ends, with the scripts I used and the
original attachment when I'm allowed to share it.

## Layout

```
<CTF name>/
└── <category>/
    └── <challenge>/
        ├── README.md       # the writeup
        └── <attachments>   # original challenge files, when available
```

## Notes

Writeups go up after the CTF has ended. Spoilers start below each challenge's
description, so stop there if you want to try it yourself first.
